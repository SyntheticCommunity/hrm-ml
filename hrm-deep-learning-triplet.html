方法原理

与 Siamese 和 Metric Learning 不同，Triplet Loss 不要求模型预测精确的距离值，而是学习样本间的相对相似性排序。训练使用三元组 (Anchor, Positive, Negative)：

\[\mathcal{L} = \max\left(0,\ \|f(A) - f(P)\|_2 - \|f(A) - f(N)\|_2 + \text{margin}\right)\]

其中：

  • Anchor (A)：参考样本的 HRM 曲线
  • Positive (P)：与 A 群落最相似的样本（BC 距离最小）
  • Negative (N)：与 A 群落最不相似的样本（BC 距离最大）
  • margin (0.3)：要求 Positive 比 Negative 更接近 Anchor 的最小间隔

为什么 Triplet 可能适用于此问题？

BC 距离本身来自 ASV 测序，存在实验噪声。精确回归噪声较大的距离值未必最优——学习”谁比谁更相似”的排序关系可能更鲁棒。

例如：两个样本的 BC 距离分别为 0.52 和 0.48，数值差 0.04 可能在测序噪声范围内，但”A 比 B 更相似于 C”这类排序关系更可信。

局限性

Triplet Loss 不约束嵌入距离的绝对值，只保证 \(d_{ap} < d_{an} - \text{margin}\)。因此训练后的嵌入空间只适合排序和检索，不适合作为距离值直接使用。

构建三元组

对 239 个样本中的每个 anchor：

  1. 选择 BC 距离最小的非自身样本作为 Positive（最相似）
  2. 选择 BC 距离 > \(d_{ap} + 0.2\) 的样本中随机一个作为 Negative（最不相似）
  3. 最多生成 5,000 个三元组，随机抽样控制训练量
def build_triplets(dm, margin=0.2, max_t=None):
    n_d = dm.shape[0]; rng = np.random.RandomState(42); tri = []
    for a in range(n_d):
        si = np.argsort(dm[a]); p = si[1]
        nc = [j for j in range(n_d) if dm[a,j] > dm[a,p] + margin]
        if not nc: nc = [j for j in range(n_d) if j != a and j != p]
        if not nc: continue
        tri.append((a, p, rng.choice(nc)))
    tri = np.array(tri)
    if max_t and len(tri) > max_t:
        tri = tri[rng.choice(len(tri), max_t, replace=False)]
    return tri

triplets = build_triplets(bc_mat, margin=0.2, max_t=min(len(y), 5000))

模型架构

class TripletEncoder(nn.Module):
    def __init__(self, encoder, margin=0.3):
        super().__init__()
        self.encoder = encoder; self.margin = margin

    def forward(self, a, p, n):
        za = self.encoder(a); zp = self.encoder(p); zn = self.encoder(n)
        d_ap = torch.sqrt((za - zp).pow(2).sum(1) + 1e-8)
        d_an = torch.sqrt((za - zn).pow(2).sum(1) + 1e-8)
        # Hinge loss: 惩罚 d_ap >= d_an - margin 的情况
        return torch.clamp(d_ap - d_an + self.margin, min=0).mean(), d_ap, d_an

    def encode(self, x): return self.encoder(x)

encoder = nn.Sequential(
    nn.Linear(n_temp, 128), nn.ReLU(), nn.Dropout(0.3),
    nn.Linear(128, 64),     nn.ReLU(), nn.Dropout(0.3),
    nn.Linear(64, 32),
)
model = TripletEncoder(encoder, margin=0.3)

model, tr_loss, vl_loss, best = train_triplet_model(

评估

Triplet Loss 不输出绝对距离值，评估重点在排序一致性。使用嵌入欧氏距离与 BC 距离的 Spearman 秩相关。

结果解读

Figure 1 展示了 Triplet 嵌入距离与 BC 距离的关系：

  • Spearman r = +0.566：排序一致性强于随机（r=0），但弱于 Metric Learning（r=0.86）
  • R² = −7.75：绝对值几乎无预测能力——嵌入距离范围 [0.03, 4.94] 远大于 BC 距离范围 [0, 1]
  • 嵌入 norm：0.47–3.54，部分样本的嵌入远偏离原点，导致 pairwise 距离失控

为何 Triplet 表现最弱？

  1. 信息利用率低：每个三元组只利用了”A-P 距离 < A-N 距离”这一个不等式，而 Siamese 和 Metric Learning 每个样本对都利用了精确的 BC 距离值
  2. Hard Negative 不足：margin=0.2 筛选的负样本往往已经是”明显更不相似”的简单样本，训练梯度主要来自边缘情况
  3. 尺度完全无约束：没有任何机制将嵌入距离映射到 BC 距离的尺度上——嵌入向量只需满足排序关系
  4. Triplet 选择随机性：对每个 anchor 随机选一个 negative，可能遗漏 hardest negative

如果希望 Triplet 方法在这个问题上表现更好，可能的改进方向包括：Hard negative mining（全局搜索最难区分的负样本）、结合 Semi-Hard Triplet 策略、或在 Triplet Loss 基础上附加正则项约束嵌入范数。
