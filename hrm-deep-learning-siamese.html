方法原理

Siamese Network（孪生网络）核心思想是权重共享：两个相同的编码器分别处理一对熔解曲线 \(x_A, x_B \in \mathbb{R}^{n}\)（\(n \approx 100\) 个温度点），输出各自的低维嵌入向量 \(z_A, z_B \in \mathbb{R}^{d}\)，合并后回归 Bray-Curtis 距离：

\[\hat{d}(x_A, x_B) = \mathbf{g}([ z_A \parallel z_B \parallel |z_A - z_B| ])\]

其中 \(\parallel\) 表示向量拼接，\(\mathbf{g}\) 是多层感知机回归器。对称设计保证 \(\hat{d}(A,B) = \hat{d}(B,A)\)，无需显式约束。

为何选择 MLP 而非 1D-CNN？

本数据集的温度点约 100 维，属于中等维度的稠密向量。实践中发现：

  • 1D-CNN 对归一化和 batch size 高度敏感，在 MPS/CPU 上容易因 BatchNorm1d 导致梯度爆炸
  • MLP 参数更少、训练更稳定，配合 z-score 标准化和梯度裁剪即可达到同等表达能力
  • 1D-CNN 的局部感受野优势在 \(\mathbin{\sim}100\) 维的输入上不显著

本实验最终采用三层 MLP（\(n \to 128 \to 64 \to 32\)）作为编码器。

训练策略关键点

先前版本的训练崩溃（R² = −3，预测恒为常数）暴露了三个关键问题，均已修复：

训练发散 → NaN loss 输入未标准化，导数跨 \([-0.004, 2.12]\) z-score 按温度点标准化

模型架构

class SiameseRegressor(nn.Module):
    """共享 MLP 编码器 + 回归头"""
    def __init__(self, input_dim, hidden=128, emb_dim=32):
        super().__init__()
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, hidden), nn.ReLU(), nn.Dropout(0.3),
            nn.Linear(hidden, 64),        nn.ReLU(), nn.Dropout(0.3),
            nn.Linear(64, emb_dim),
        )
        # 合并 [z1, z2, |z1 - z2|] 后回归标量距离
        self.regressor = nn.Sequential(
            nn.Linear(emb_dim * 3, 32), nn.ReLU(), nn.Dropout(0.2),
            nn.Linear(32, 1),
        )

    def forward(self, x1, x2):
        z1 = self.encoder(x1); z2 = self.encoder(x2)
        return self.regressor(torch.cat([z1, z2, torch.abs(z1 - z2)], dim=1))
  • 编码器：\(n \xrightarrow{\text{128}} \xrightarrow{\text{64}} \xrightarrow{\text{32}}\)，每层含 Dropout 0.3 正则化
  • 回归头：接受 \(3 \times 32 = 96\) 维输入（两个嵌入 + 绝对值差），输出标量距离
  • 总参数量约 \(n \times 128 + 128 \times 64 + 64 \times 32 + 96 \times 32 + 32 \times 1 \approx 25\)k，极小

训练

AdamW 优化器（weight decay \(10^{-3}\)）+ CosineAnnealingWarmRestarts 调度器 + clip_grad_norm_(1.0) 梯度裁剪。MSE 损失函数，最大 200 epochs，early stopping patience=30。

model = SiameseRegressor(n_temp, hidden=128, emb_dim=32)
model, tr_loss, vl_loss, best = train_regression_model(
    model, ds_train, ds_val, device=device,
    epochs=200, lr=1e-3, batch_size=256, patience=30
)

评估

在测试集（5,689 对，未参与训练和验证）上评估。预测值经过逆标准化还原到原始 BC 距离尺度。

import matplotlib.pyplot as plt
from sklearn.metrics import r2_score, mean_squared_error

pred_n = predict_all(model, ds_test, device)
pred = pred_n * y_std + y_mean
y_t = y_raw[i_test]

rmse = np.sqrt(mean_squared_error(y_t, pred))
r2   = r2_score(y_t, pred)
spear = np.corrcoef(y_t, pred)[0,1]
print(f"RMSE={rmse:.4f}  R²={r2:+.4f}  Spearman r={spear:+.4f}")

fig, ax = plt.subplots(figsize=(6,5))

ax.set_ylabel('Predicted Distance')

结果解读

Figure 1 展示了模型在测试集上的表现：

  • R² = +0.9838：模型解释了 BC 距离中 98.4% 的方差，接近完美预测
  • Spearman r = +0.9924：预测与真实的排序几乎完美一致
  • RMSE = 0.0419：相比 BC 距离的标准差 0.33，误差约为标准差的 1/8

作为对比：未经学习的原始 HRM 欧氏距离与 BC 距离的 Spearman r 仅为 0.36（见评估章节），Siamese 网络将相关性从 0.36 提升至 0.99，效果提升巨大。这表明 MLP 编码器从原始熔解曲线中提取到了与群落组成高度相关的非线性特征。

需要注意的是 R² 极高（0.984）可能存在一定过拟合——测试集与训练集来自同一批玉米种子数据，真正泛化能力需要通过独立数据集交叉验证确认。
