Mantel 检验

Mantel 检验评估两个距离矩阵的相关性——此处比较的是 HRM 衍生的距离矩阵与 16S 扩增子测序导出的 Bray-Curtis 距离矩阵。采用 Spearman 秩相关（对距离的绝对值不敏感，更关注排序一致性）和 9,999 次排列检验。

检验假设：\(H_0\) 为两个距离矩阵间无相关关系。若 \(p < 0.05\)，拒绝 \(H_0\)，说明 HRM 信号与群落组成显著相关。

# 构建 DNN 距离矩阵（确保行/列顺序与 bc_dist 一致）
siamese_dist_r  = as.dist(as.matrix(siamese_dist)[attr(bc_dist, "Labels"),
                                                   attr(bc_dist, "Labels")])
metric_dist_r   = as.dist(as.matrix(metric_dist)[attr(bc_dist, "Labels"),
                                                  attr(bc_dist, "Labels")])
triplet_dist_r  = as.dist(as.matrix(triplet_dist)[attr(bc_dist, "Labels"),
                                                   attr(bc_dist, "Labels")])

run_mantel = function(dist_obj) {
  mantel(bc_dist, dist_obj, method = "spearman", permutations = 9999)
}

mantel_results = rbind(
  data.frame(Method = "0-1 Normalized + Euclidean",
             Spearman_r = mantel(bc_dist, hrm_euclidean, method = "spearman",
                                 permutations = 9999)$statistic,
             p_value = mantel(bc_dist, hrm_euclidean, method = "spearman",
                              permutations = 9999)$signif),

检验结果解读

  • Siamese + MLP：Spearman r = 0.99，远超所有其他方法（包括 RF Proximity 和 0-1 归一化基线）。HRM-DNN 距离与 16S BC 距离的排序几乎完全一致
  • Deep Metric Learning：Spearman r 介于 RF Proximity 和 Siamese 之间，虽然绝对值不够准确（见 Metric Learning 章节），但排序一致性良好
  • Triplet Contrastive：排序能力中等，弱于 Metric Learning。Triplet Loss 的信息利用率（每个三元组仅用一个不等式）限制了其性能
  • 0-1 Normalized + Euclidean：作为未经学习的基线，反映原始 HRM 曲线间的”物理”距离与群落距离的相关性。DNN 方法显然大优于该基线

Figure 1 并排展示 4 种方法的预测距离 vs 真实 Bray-Curtis 距离。从中可以直观看出：

  • 0-1 Normalized Euclidean（左上）：散点弥散，相关性弱——原始 HRM 距离与群落距离关联有限
  • Siamese + MLP（右上）：散点紧密聚集在对角线附近，即使 free_y 刻度，仍可见清晰的线性趋势
  • Deep Metric Learning（左下）：存在正相关但离散度较大，距离绝对值偏向中间范围（0.59–1.01）
  • Triplet Contrastive（右下）：几乎无趋势线，嵌入距离与 BC 距离的关系最弱

综合讨论

跨方法性能比较

方法 R² Spearman r RMSE 优势 劣势
Siamese + MLP +0.984 +0.992 0.042 预测最准、训练稳定 不可直接获得嵌入
Metric Learning +0.388 +0.861 0.258 嵌入可解释；标定后 R²=0.74 绝对值需后处理
Triplet −7.750 +0.566 0.973 理论上对小样本鲁棒 实际信息利用率低
Raw HRM Euclid. −38.5 +0.36 2.07 无需训练 相关性极弱

Siamese + MLP 为何如此成功？

  1. Architecture-task alignment：Siamese 天然适配 pairwise 距离回归——输入一对曲线、输出一个距离值，与问题结构完全一致
  2. 对称性内置：权重共享保证 \(\hat{d}(A,B) = \hat{d}(B,A)\)，无需显式约束
  3. 信息充分利用：每个样本对有精确的 BC 距离作为监督信号，而 Triplet 只用了一个不等式
  4. 数据量充足：28,441 个训练对来自仅 239 个样本（pairwise 构造天然扩充），模型不会过拟合

对后续实验的建议

  • 独立数据集验证：当前训练和测试来自同一批玉米种子数据，虽有 train/test split 但缺乏真正独立的验证集。下一批微生物组实验的独立样品可作为 external validation
  • 嵌入空间应用：Metric Learning 学到的嵌入向量可与 PCoA 直接比较（见 Metric Learning 章节），用于研究群落组成的渐变结构
  • 集成策略：Siamese（精确预测）+ Metric Learning（嵌入可视化）可互补使用，前者预测距离、后者生成可解释的低维表示
