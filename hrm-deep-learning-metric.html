方法原理

Deep Metric Learning 的目标是学习一个编码映射 \(f: \mathbb{R}^{n} \to \mathbb{R}^{d}\)，使得嵌入空间中样本间的欧氏距离直接等于 Bray-Curtis 距离：

\[\mathcal{L} = \frac{1}{N} \sum_{(i,j)} \left( \|f(x_i) - f(x_j)\|_2 - \text{BrayCurtis}(i, j) \right)^2\]

与 Siamese 的最大区别：嵌入向量的欧氏距离本身就是预测值，无需额外的回归头。这使得嵌入空间具有直接的可解释性：

  • 两个样本在嵌入空间中距离越近 → 微生物群落越相似
  • 嵌入向量可以直接用于聚类、t-SNE/UMAP 可视化、下游分析
  • 新样本的嵌入可以通过一次前向传播获得，无需 pairwise 预测

挑战与解决

Metric Learning 的困难在于同时满足两个约束：(1) 嵌入距离的绝对值须匹配 BC 距离，(2) 嵌入须在 Tanh 约束的空间中找到几何排列。实践中，不加回归头的直接距离回归尺度容易偏移——模型可能学到正确的排序（Spearman r 高）但绝对值不准（R² 低）。我们在结果中展示：嵌入距离仅需一次线性标定即可大幅改善 R²。

模型架构

class DeepMetricLearning(nn.Module):
    """深度度量学习：嵌入欧氏距离直接预测"""
    def __init__(self, encoder):
        super().__init__()
        self.encoder = encoder
    def forward(self, x1, x2):
        z1 = self.encoder(x1); z2 = self.encoder(x2)
        return torch.sqrt(torch.sum((z1-z2)**2, dim=1, keepdim=True) + 1e-8)
    def encode(self, x):
        """编码单个样本为嵌入向量——关键 API"""
        return self.encoder(x)

encoder = nn.Sequential(
    nn.Linear(n_temp, 128), nn.ReLU(), nn.Dropout(0.3),
    nn.Linear(128, 64),     nn.ReLU(), nn.Dropout(0.3),
    nn.Linear(64, 32),  # 32 维嵌入，便于可视化和下游分析
)
model = DeepMetricLearning(encoder)

model, tr_loss, vl_loss, best = train_regression_model(
    model, ds_train, ds_val, device=device,
    epochs=200, lr=1e-3, batch_size=256, patience=30)
print(f"Metric Learning: epoch={best} val_MSE={min(vl_loss):.6f}")
Metric Learning: epoch=53 val_MSE=0.621581
  • 编码器架构与 Siamese 完全一致（\(n \to 128 \to 64 \to 32\)），便于公平比较
  • forward 方法直接返回 \(|z_1 - z_2|_2\)，无回归头
  • encode 方法提供单个样本的嵌入提取，用于可视化和聚类

结果解读

Figure 1 展示了 Metric Learning 在测试集上的表现：

  • Spearman r = +0.861：嵌入空间学到了正确的排序——相似群落的嵌入距离更近
  • R² = +0.388：绝对值不够准确——预测范围 [0.59, 1.01] 窄于真实范围 [0.003, 0.998]
  • RMSE = 0.258：约为 BC 标准差的 78%

嵌入距离的尺度偏移是 Metric Learning 的典型特征：没有回归头约束绝对值，模型倾向于输出”安全”的中间值。补救方案：线性尺度标定：

根据实验，在训练集上拟合 \(y = \alpha \cdot d_{\text{embed}} + \beta\) 并将此映射应用到测试集： - 标定后 R² = +0.740（从 0.388 大幅提升） - Spearman r 不变（线性变换不改变排序）

这说明嵌入空间确实学到了群落组成结构，只是距离的绝对尺度需要校准。对于仅需排序的应用场景（如相似样本检索、聚类），标定并非必须。

嵌入空间可视化

Metric Learning 的一个核心优势：编码后的嵌入向量可以直接可视化和分析。

from sklearn.manifold import TSNE, MDS

temp_cols_all = [c for c in ss.columns if c.startswith("T")]
